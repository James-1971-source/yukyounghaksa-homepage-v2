# 사회복지법인 육영복지재단 육영학사 공식 홈페이지 (2차 버전 - 신생원 디자인 스타일)

본 프로젝트는 **사회복지법인 육영복지재단 육영학사**의 모든 콘텐츠(메뉴 구조, 기능, 세부 텍스트, 아동 인권보호 기준 등)를 100% 유지하면서, **신생원 홈페이지의 그린·웜톤 비주얼 디자인 및 레이아웃**을 적용한 2차 버전 웹사이트입니다.

## 주요 특징
- **디자인 시스템**: 신생원 스타일 그린 테마 (`#4cab6e` / `#3b8f5a` / `#ffb400`), 상단 고정형 GNB 헤더 및 중앙 드롭다운(`.gnb-2dep`), 풀와이드 메인 비주얼 슬라이더(`#mainVisual`), 플로팅 6구 퀵 아이콘 바(`.quick-menu`), 2단 공지/이야기 보드(`.notice-section`), 3단 포토 갤러리(`.gallery-section`), 패럴랙스 CTA 배너(`.cta-band`), 4단 빠른 서비스 안내(`.quick-banner-section`), 무한 롤링 유관기관 배너(`.partner-slider-section`), 서브페이지 비주얼 배너(`.sub-visual`) 및 그린 브레드크럼 바(`.sub-lnb-bar`) 적용
- **콘텐츠 및 기능 100% 보존**:
  1. **학사소개**: 시설장 인사말, 법인 및 시설소개(미션·비전·핵심가치), 최신 연혁, 조직 및 업무(직제표), 시설현황 및 전경(인터랙티브 갤러리), 오시는 길
  2. **입소안내**: 입소대상 및 절차, 입소상담 안내
  3. **사업 및 프로그램**: 10대 영역 프로그램 안내, 특성화 자립프로그램 「꿈JOB끼」
  4. **후원 및 자원봉사**: 후원안내(계좌·CMS·지정기탁·해피빈), 온라인 후원신청, 자원봉사 안내(VMS 연계), 온라인 자원봉사신청
  5. **자립정보센터**: 자립정보 게시판(주거·금융·취업·장학·심리 카테고리 필터), 자립지원전담기관 연계
  6. **알림마당**: 공지사항, 육영 소식지(아카이브), 육영학사 이야기(갤러리), 개인정보처리방침(아동정보·초상권 보호 원칙)
- **데이터베이스**: Firebase Firestore (`yukyounghaksa-official`) 실시간 연동 및 `localStorage` 하이브리드 폴백 지원
- **관리자 센터**: 하단 푸터 `관리자센터` 버튼을 통해 공지사항·육영학사 이야기 등록/삭제 및 온라인 후원·자원봉사 신청내역 열람 (초기 비밀번호: `1009`)

## 실행 및 배포

```bash
npm install
npm run build
npx firebase-tools deploy --only hosting --project yukyounghaksa-official
```
